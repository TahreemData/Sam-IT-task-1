## 📌 Project Overview

This project focuses on building a **machine learning classification system to predict whether a patient has heart disease** based on medical and clinical attributes.

The project was completed as part of a **Data Science Internship – Task 1: Heart Disease Prediction**.

The workflow covers data preprocessing, exploratory data analysis, feature selection, classification model development, model comparison, and performance evaluation.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Predict whether a patient has heart disease
- Perform data cleaning and preprocessing
- Handle missing values and inconsistent data
- Analyze relationships between medical features
- Select relevant features for prediction
- Train multiple classification algorithms
- Compare classification model performance
- Evaluate models using:
  - Accuracy
  - Precision
  - Recall
  - F1-Score
- Visualize model performance
- Analyze the confusion matrix

---

## 📂 Dataset

The project uses the **Heart Disease Dataset** from Kaggle.

The dataset contains medical and clinical attributes that can be used to identify the presence or absence of heart disease.
